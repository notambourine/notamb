notamb

Sticky A/B bucketing you paste, not install. notamb('hero') returns a variant, remembers it per browser, and reports the exposure to your analytics.

GitHub umami-shopify (sister project)

Use it

const variant = notamb('hero');      // 0 or 1, sticky for this browser
if (variant === 1) document.body.classList.add('hero-b');

notamb('cta-copy', 3);               // three-way test → 0, 1, or 2

Assignment is uniform random, persisted in localStorage under notamb:<test>. The exposure fires once per test per page load — SPA route changes don't re-fire it. Analyze by unique visitors per variant, not raw events.

Where exposures land

  • GA4 — dataLayer.push({event: 'ab_assigned', notamb_test, notamb_variant}), readable by gtag.js and GTM. Register the two params as custom dimensions to report on them.
  • Umami — umami.track('ab_assigned', {test, variant}), with a short poll so a deferred Umami script still catches the event.
  • umami-shopify — Shopify.analytics.publish('umami:ab', {test, variant}); the custom pixel forwards each publish to Umami as one ab_assigned event, sequenced after the pageview.
  • Shopify cart — POST /cart/update.js with a private __notamb_<test> attribute, so the variant rides through checkout onto the order and you can group revenue by it in the Admin API. Once per session rather than per pageview, because every cart write clears the browser's prefetch cache. Express checkout (Buy It Now, Shop Pay) skips the cart, so those orders carry no attribute.
